Privacy Policy

Last updated: 2026-11-05

Lofi Factory ("the app") is a personal tool used only by the owner of the YouTube channel @LOFI_MUSIC-o2w.

What data the app uses

  • The app uses the YouTube Data API with the owner's authorization to upload videos, set thumbnails, and add videos to playlists on the owner's own channel, and to read that channel's basic information (to confirm the correct channel is signed in).
  • The OAuth token is stored only on the owner's private computer, with access restricted to the owner. It is never shared, sold, or sent to any third party.

What the app does not do

  • It does not collect, store, or process data about any other person or YouTube user.
  • It does not use Google user data for advertising, analytics, or any purpose other than uploading the owner's own videos.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Data retention and deletion

The app stores no YouTube data other than the OAuth token and the IDs of videos it uploaded. The token is deleted from the owner's computer when the app is retired or when access is revoked. To request deletion of any stored data, email the contact address below; it will be deleted within 7 days.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
